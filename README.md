# StudyHub API

StudyHub API es un proyecto académico desarrollado para la asignatura de Desarrollo Web en Entorno Servidor.

El objetivo del proyecto es crear una API REST local para la gestión de estudios, basada en una especificación OpenAPI y conectada a una base de datos MySQL. Además, incluye un cliente web que consume los servicios de la API mediante JavaScript.

## Tecnologías utilizadas

- PHP
- MySQL
- Apache
- XAMPP
- JavaScript
- HTML
- CSS
- OpenAPI

## Funcionalidades previstas

- Conexión con base de datos MySQL.
- Servicio REST para consultar estudios.
- Cliente web consumidor de la API.
- Estructura preparada para trabajar en entorno local con XAMPP.
- Posible integración adicional con servicios externos.
